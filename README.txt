ЩО ВСЕРЕДИНІ
- index.html — головна сторінка
- styles.css — дизайн і адаптивність
- script.js — мобільне меню, вибір послуги, AJAX-форма
- privacy.html — текст про обробку звернень
- assets/ — п'ять фото, оригінальний логотип, його темний варіант для світлого фону, фірмовий символ і favicon.png

ЯК ПЕРЕГЛЯНУТИ
Розпакуйте архів і двічі натисніть index.html.
Щоб перевірити саме роботу форми, використовуйте опублікований сайт
або локальний сервер (перегляд з file:// може блокувати запити).

ПУБЛІКАЦІЯ НА GITHUB PAGES
1. Створіть репозиторій на GitHub.
2. Завантажте ФАЙЛИ з цієї папки в корінь репозиторію (index.html має лежати у корені).
3. У Settings → Pages виберіть Deploy from a branch, main, /(root), Save.
4. Коли з'явиться адреса сайту, відкрийте його та перевірте сторінки на телефоні.
5. Надішліть ОДНУ тестову заявку. Перевірте її в акаунті Formspree і на пошті.
